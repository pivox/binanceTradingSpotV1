# Projection UI - Mode Backtesting

Prototype visuel:

- [backtesting-mode-projection.html](backtesting-mode-projection.html)

## Intention

Ce fichier HTML projette l'experience cible du mode Backtesting de Tradebot:

- preparation des donnees historiques;
- configuration d'un run;
- dashboard de performance;
- graphe avec entrees, sorties, SL, TP et zones R;
- explication des signaux MTF;
- table de trades;
- comparaison de calibrations;
- rapport go/no-go.

Le prototype utilise des donnees fictives et ne lance aucun appel API.
